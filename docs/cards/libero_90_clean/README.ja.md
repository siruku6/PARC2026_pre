# libero_90_clean

*English: [README.md](README.md)*

**LIBERO の `libero_90`（90 課題）から、対象外の物にぶつかる手本を取り除いた版である。**
**末尾 250 本は撮り直した手本**で、これがこのデータの替えの利かない部分である。

| | |
|---|---|
| 本数 | **3,911** |
| コマ数 | **560,254** |
| 課題数 | **73** |
| 形式 | LeRobot v3.0・20 Hz |

## 何のためか

**`libero_90` の部分だけ、接触の掃除が後回しになっていた。**
LIBERO-plus の 40 課題は接触で選り分けたが、`libero_90` は**300 コマを超える 10 本を外しただけ**
だった——**判定に要る本家の hdf5（66.7 GB）が手元に無かったためである。**

**2026-09-16 にそれを済ませた。**その結果がこのデータで、
[`libero_combined_bowl5_initpose_l90clean`](https://huggingface.co/datasets/siruku6/libero_combined_bowl5_initpose_l90clean)
の 250 本を入れ替えるときの**部品**になっている。

## 何を「汚れ」と判定したか

**対象外の物体に触れているか、動かしているか。**本家の `libero_90` の hdf5 にある
生の MuJoCo の状態から測った（再生はしていない）。

| | |
|---|---|
| 基準のコマ | 10 コマ目（0・5・10・20 から選ぶ） |
| 変位 | **3 軸の絶対値の和** |
| 境目 | **1.0 mm**（採点器と同じ） |
| 対象外の物体 | 観測の `<name>_pos` のうち、`robot0*` でも `_to_robot0_eef_pos` でもなく、bddl の `:obj_of_interest` に無いもの |

**4,500 デモを測った結果**——1 mm 超動かしたもの 296、触れたもの 296、どちらかに当たるもの **363（8.1 %）**。
混合データセットの `libero_90` 部分 3,911 本のうち、**250 本を汚れと判定した。**

## 中身の内訳

**測って確かめた**（腕 6 次元の行動列を sha256 で突き合わせ・2026-09-19）。

| 部分 | 本数 | 出どころ |
|---|---|---|
| 先頭（番号 0〜3660） | **3,661** | **配布データそのもの**——3,661 本すべてが配布 `libero_combined_20hz` と腕の動きまで一致した |
| 末尾（番号 3661〜3910） | **250** | **うち 223 本は配布データのどこにも無い＝撮り直した手本。**残る 27 本は配布データと一致する |

**だからこのデータは消せない。**223 本は台本の方策を回し直さないと同じものにならない。

**指の値は `±1` に直してある**（配布データの `{0,1}` のままでは「開く」に逆の正解が付く）。

## 使われ方

**混合データセットの埋め戻しに使う。**親の `libero_90` 部分（番号 17731〜21641）から
汚れた 250 本を外し、**このデータの末尾 250 本を同じ数だけ末尾に足す。**
課題ごとの本数は変わらず、コマ数だけ減る（**−5,803**）。

**対応は名前や長さではなく、行動列の sha256 で決めてある**——
`(課題, 長さ)` の一致では 250 本を一意に決められないためである。

**組み方の一式は
[`libero_plus_bowl5_initpose` の `rebuild/`](https://huggingface.co/datasets/siruku6/libero_plus_bowl5_initpose/tree/main/rebuild)
にある。** 2026-09-18 に別のマシンで実際に通し、**21,642 本すべての行動列が一致した。**

## 分かっている弱点

- **撮り直した 250 本を作った手続きが、スクリプトになっていない。**2026-09-16 に手で実施した。
  **どの本をどこへ入れたかの台帳は残してある**（`l90clean_replace.json`）が、
  **同じ 250 本をもう一度作る手順は残っていない。**
- **`libero_90` には初期姿勢を振った手本も、見た目を振った手本も無い。**
  それらは LIBERO-plus の 40 課題側にしかない。**課題によって手本の質が揃っていない。**
- 外観を重ねた姉妹版が
  [`libero_90_clean_appearance`](https://huggingface.co/datasets/siruku6/libero_90_clean_appearance)
  にあるが、**埋め戻しに使ったのはこちら（重ねていない側）である。**
