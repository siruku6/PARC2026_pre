■ わかったこと 1: 色語は無視されている
VLM の内部表現（action expert が cross-attend する KV）で、10 個の指示が互いにどれだけ離れているかをコサイン距離で測り、総当たりで平均しました（自然文を 1.00x とした相対値）。
これは行動ではなく表現を測っているので、上の指標とは別物です。
言語トークンの位置だけを取り出しています（全体を平均すると画像 250 個に薄まるため）。
表現の分離度 / 10 個の指示文の作り方

```
1.00x   実タスク文（句ごと違う）
0.16x   無意味語 10（banana / helicopter …）
0.00x   task_0 .. task_9（不透明な ID）
0.00x   色語 10（black / silver / red …）
```

下 2 つはどちらも実質ゼロ。両者の大小は測定の分解能内なので主張しない

色語 10 個は実質ゼロで、不透明な ID と同じでした。
つまり black bowl と silver bowl を、このモデルは task_0 と task_7 程度にしか区別していません。
効いているのは on the stove / next to the cookie box のような句の構造だけです。
