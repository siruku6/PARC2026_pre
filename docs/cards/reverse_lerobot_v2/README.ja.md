# reverse_lerobot_v2

*English: [README.md](README.md)*

**「逆向き」の課題——物を入れるのではなく、出す——のための、LeRobot 形式の実演データである。**
すべて模擬器の中で台本の方策が作った。配布データの絞り込みではない。

| | |
|---|---|
| 本数 | **397** |
| コマ数 | **61,430** |
| 課題数 | **3** |
| 形式 | LeRobot v3.0・20 Hz |

## 何のためか

**PARC2026 の Track3 が「逆向き」の課題だった**（運営の開示・2026-08-28）。
順方向のデータが「スープ缶をトレイに入れる」なら、Track3 は
**「缶をトレイから出して机に置く」**と聞いてくる。

**順方向だけで学習した重みは、Track3 のどの提出でも 8 本中 0 本だった。**
それを埋めるために作った。

| 課題 | 中身 |
|---|---|
| 黄色い本 | 棚から出す |
| アルファベットスープの缶 | トレイから出す |
| 赤いマグ | 左の皿から下ろす |

**指示文は Track3 の bddl とバイト単位で一致させてある**（397 本すべて）。
**Track3 の 4 つ目の課題「2 つのマグ」には 1 本も無い。**

## どう作ったか

**「順方向の手本の行動を逆順に流したもの」ではない。**
**シムを普通に前へ進めて録ったエピソードである。**

**時刻反転を使うのは、掴んだ物を運ぶ復路の基準の経路を作るところだけ**で、
**近づいて掴むまでの区間は合成している。**——順方向の手本には「掴む前にどう近づくか」の
情報しか無く、「出したあとどこへ置くか」は入っていないからである。

1. `gripper_shift_sweep.py` で（順方向の手本 × 配布の初期状態）の組を総当たりする
   （最良の組み合わせは `--mode phased --init-source t3 --grasp-frame clamped --standoff 0.06`）
2. **書き出さずに 1 度回してから、最小費用割当**（`scipy.optimize.linear_sum_assignment`）で、
   **配布の 50 通りの初期状態それぞれに、いちばん質の良い手本を 1 つずつ割り当てる**
3. 逆向きの目標に届いた本だけを npz に書き、`npz_to_lerobot.py` で LeRobot 形式にする

## v1 から何を直したか

v1（`reverse_lerobot_389`・389 本・67,775 コマ）から 3 つ変えた。

- **回転の頭打ちを、成分ごとの切り落としではなく、回転ベクトル全体の縮小にした**（`ROT_LIMIT=0.375`）
- 本の課題から水平出しの動きを外した
- 持ち上げたあとに 80 コマ静止させる

| | v1 | v2 |
|---|---|---|
| \|z\| が 10 を超えるコマ | 15.2 % | **0.0 %** |
| \|z\| の最大 | 26.1 | 9.8 |
| 落下 | 40 mm / 37 mm | **1.0 mm / 2.9 mm** |
| 赤いマグ | 139 本 | 147 本 |
| 合計 | 389 本 | **397 本** |
| 長さの中央値 | 173 | 152 |

## 分かっている弱点

- **物を共有する順方向の課題を壊す。**逆向きを 49.5 % 混ぜて学習させたところ、
  **同じ物を使う順方向の行が 22〜25 ポイント下がった**（他の行は横ばい）。
  **混ぜる比率は、下げ幅と引き換えである。**
- **Track3 の提出点は最後まで 0.000 のままだった。**手元の評価では
  この系統で初めて 0 でなくなった（0.000 → 0.0235）が、**採点には届かなかった。**
- **「2 つのマグ」の課題には手本が無い。**
- **腕の初期姿勢が、すべての本で同じである。**
- **色だけで見分ける課題は学習できていない。**

## 混ぜ方

[`siruku6/jaist_mix_v2`](https://huggingface.co/datasets/siruku6/jaist_mix_v2)（6,176 本）は、
**`libero_plus` を課題あたり 75 本に間引いたもの（3,000 本）と、このデータを 8 倍に複製したもの
（397 × 8 = 3,176 本）**を混ぜたものである。**逆向きの割合は 49.5 %。**

```bash
COPIES=8 PER_TASK=75 REV_DIR=work/artifacts/reverse_lerobot_v2 \
MIX=jaist_mix_v2 bash solution/train/jaist_dataset_build.sh
```

**正規化の統計は元の側に固定してある**（差 0.000e+00）。

**混ぜたもののうち 3,176 本は、この 397 本の 8 つの複製である。**
**部品で持てば 8 分の 1 で済む。**
