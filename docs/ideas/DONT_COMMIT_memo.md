# Background

現在、コンペの Track 3 の逆向きタスクをうまくこなせるような学習をするために、新規に学習データを作りたいと考えている。

しかしながら、かなりの時間をかけて作った学習データがあっても、ごく一部のロールアウトでしか成功を収められていない。

# Idea

以下のタスクに関してアイデアがある

- docs/talk/inner_sessions
    - 20
    - 21
    - 25
    - 28

1 step ごとの移動速度／角速度が速すぎる、または位置座標が角度の差分が大きすぎるために、学習してもロボットが真似できていない可能性もあると考えている。

勾配がずっと1を超えていたことの原因としてこれを考えている。

# 028 の現状

4061, 4062 をみましたが、final は非常に無駄が多いことがわかりました。
これは学習データにするのは適切ではないです。

無駄の内容は以下の通り

- 上昇した後の静止
- 元からある動きだが、自作軌道部分と逆再生の間の繋ぎ目で、逆再生が持っている非効率な動きに合わせて大きく本を回転させている
- 本を掴んだ後の動きが遅すぎる上に一定である (掴んだ直後遠く寸前は少しゆっくりで、その間は早くなっていると良い)
- 結局本が倒れている (倒さないように垂直に置く)

また、4061 62 63 いずれもほぼ同じ動きであり、これらを全て学習する必要性をあまり感じません。なぜこのようにほぼ同じ動き、配置になっているのでしょうか。
