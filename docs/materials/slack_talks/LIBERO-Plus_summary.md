# 言い方を変えると成功率が大きく落ちる

## 実験1: 指示を消した場合

言語入力を空にして画像だけ与えると、成績がほとんど変わらなかった。
つまり、モデルにとって指示文はあってもなくても同じ。

ただし、例外もあり、複数の作業を順にこなす Long suite では、指示を消すと成績が落ちら。長い作業は指示に頼らざるを得ないと推測される。

## 実験2: 指示の対象物をすり替えた場合

同じ机の上に、 alhabet soup と butter がおいてあります。元の指示は「alphabet soup を取って」であるが、これを「butter を取って」にすり替えて実験を実施。
すると、成功率がほぼゼロに落ちた。指示を変えてもモデルは相変わらず alhabet soup を取ろうとする。

つまり、指示文の内容はモデルにとって無視されている。
言葉ではなく、見た景色に反応して行動していたことがわかった。


# カメラの角度ずらしは、わずかなずれを学習すれば十分

5度程度のズレを学習したモデルは、15~75度のズレに対応ができた。

ただし、1 アームの初期姿勢のズレがあった場合、2 対象物の位置がずれていた場合、の2通りの学習はあまりうまくいっていない。
この2点が LIBERO-Plus 後も残る課題である。
