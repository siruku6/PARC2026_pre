# 36. 使わなくなった道具は、間違った出どころを教え続ける

**2026-09-17 の提出（22.0.0）は、π0.5 の `vlm/` に SmolVLM2 のトークナイザが入った状態で
採点され、Track1 が 0.498 → 0.075 になった。**

**打ったコマンドが間違っていた、では説明が足りない。**
**正しく見えるコマンドが手近にあった**というのが起きたことである。

## 4 つが重なっている

| | |
|---|---|
| **1. 道具が置き場を汚していた** | `fetch_base_weights.sh` が `model_weights/vlm/` を **SmolVLM2 のトークナイザで埋める。**構造上そうなっている |
| **2. 別の道具がそこを出どころとして教えていた** | `install_weights.py` の `_INHERITED_DIRS = ("vlm",)`。**SmolVLA 時代に書かれ、π0.5 が来ても直されなかった** |
| **3. 検査が有無しか見なかった** | `build_submission.py` は `model_weights/vlm/` の存在だけを確かめていた。**GPT2 のトークナイザ 11 個でも通る** |
| **4. その日に限って、異常の合図が動いていた** | ライセンス同梱でエントリ数が **541 → 544** に変わった日だった。**551 を見ても「増えたぶんか」と読めてしまう** |

## 手順書の中で矛盾していた

**同じファイルの 150 行違いに、逆のことが書いてあった。**

| 行 | 何と書いてあったか |
|---|---|
| 96 | いま `model_weights/vlm/` にあるものを引き継ぐ。**手作業では必ず取りこぼす** |
| 243 | `cp -R work/artifacts/pi05_rp3000/vlm <重み>/vlm`。**SmolVLA のものを入れてはならない** |

**先に出てくるほうが強い言い方だった。**

## 次はこうする

- **使わなくなった道具は、消すか、渡されたものを見て止める。**残すなら
  「何のためのものか」を**実行時に**言わせる。読み手が節の見出しを覚えている前提にしない。
- **検査は「有る」ではなく「正しい」を見る。**存在確認は、間違ったものが置かれた場合に
  何も言わない。**名前・種類・数のどれかを突き合わせること。**
- **合図に使っている数字を動かす日は、動いた先の値を先に決める。**
  「いつもと違う」で気づく仕組みは、いつもが変わった日に効かない。
