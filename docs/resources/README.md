# resources/ — 今使えるものの一覧

**`reference/` と違って、ここは過去を残さない。** 状態が変わったら上書きし、常に「今どうなって
いるか」だけが書かれている状態を保つ。マシンを借りた／返した、docker image を再ビルドした、
重みを HF に上げた／消した、といった変化があったら、その都度該当ファイルを直す。

## ここに書くもの / 書かないもの

**書くのは「今使える資源が、どれだけ、どこにあるか」だけである。** 資源とは計算機・GPU・
メモリ・ディスク・モデルの重み・学習データ・docker image を指す。**それをどう扱うかの手順や
Tips は、ここではなく `howto/` と `knowledge/` に書く。**

| | 例 | 置き場 |
|---|---|---|
| **書く** | GPU が何枚で VRAM が何 GB か・どの重みがどこにあって何 GB か・どの image が今あるか・どのコンテナが動いているか | このディレクトリ |
| **書かない**（手順） | ディスクの空け方・重みの運び方・学習の回し方・評価の回し方 | [../howto/](../howto/) |
| **書かない**（知見） | 踏んだ事故と回避策・測って分かった傾向 | [../knowledge/](../knowledge/) |
| **書かない**（履歴） | 過去にどの重みでどの版を出して何点だったか | [../reference/19_weights_catalog.md](../reference/19_weights_catalog.md) |

**判定に迷ったら「状態か、やり方か」で分ける。** 上書きされて消えても困らない数字（`df` や
`docker ps` を見れば分かること）は状態、次に同じ場面で読み返したいものは手順か知見である。

| ファイル | 中身 |
|---|---|
| [infra_and_docker.md](infra_and_docker.md) | 使える計算資源（このマシン・運営配布 GPU・RunPod・Mac・Colab）と、Docker image・コンテナの現状 |
| [huggingface.md](huggingface.md) | HF 上に置いてあるモデル・提出 zip と、ローカルにある重みの控えの有無 |
