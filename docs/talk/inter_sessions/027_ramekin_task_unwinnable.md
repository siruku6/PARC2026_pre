## 背景（先に読んでほしい）

**このコンペで何をしているか。** PARC2026 である。ロボットアーム（Franka Emika
Panda）に言葉で指示して机の上の物を操作させる方策を作り、シミュレータ
（LIBERO / LIBERO-plus）の中で採点される。こちらの方策は公開の基盤モデル
π0.5 を追加学習したものである。

### 採点は「目当て以外の物が 1 mm 動いたら失格」である

`pipeline/rollout.py` の判定はこうなっている。

| 何 | 中身 |
|---|---|
| 対象外の物体 | 観測の `<名前>_pos` のうち、`robot0` で始まらず、`_to_robot0_eef_pos` で終わらず、bddl の `:obj_of_interest` に無いもの |
| ずれの測り方 | **3 軸の絶対値の和**（ユークリッド距離ではない） |
| 失格の境目 | **0.001 m**（`threshold_m`） |
| 基準の位置 | 初期状態を入れて**空撃ち 10 歩を打ったあと**の位置 |

### この課題は、その規則のもとでは成功しようがない

**課題は `pick up the black bowl on the ramekin and place it on the plate`。**


**掴む相手の黒い椀が、対象外のラメキンの上に載っている。**持ち上げれば

**人が操作した本家の手本 39 組すべてがこれに当たった**（[026](026_contact_demo_cleanup.md)
の報告 5 節）。ずれの中央は 10.99 mm、最悪は **245.47 mm**（ラメキンごと
持ち上がって落ちる）。**1 mm を下回った回は 1 つも無い。**

動画は `work/artifacts/contact_videos/` の
`pick_up_the_black_bowl_on_the_ramekin_and_place___typical__demo_6.mp4` と
`…__worst__demo_14.mp4`。

## 何をしてほしいか

**この課題の手本を作り直してほしい。**成果物は **(1) ラメキンを 1 mm 以上
動かさずに椀を持ち上げて皿へ置く手本**と、**(2) それが本当にそうなっている
ことを示す動画**である。

## なぜ要るか

**「採点規則のもとで成立しない課題がある」ことが分かった以上、
同じ形の課題が本選 2・3 に出たときに同じ穴に落ちる。**
**この 1 課題で作り方を確立しておけば、次はその型を当てるだけで済む。**

**そして手元の評価が歪んでいる。**`EVAL_TASKS.csv` にこの課題が入っているので、
**方策がどれだけ上手くなってもこの行は失格のままである。**手元の点を読むときに
この行を除くのか、直した手本で測り直すのかを決める必要がある。

## 前提となる事実

| 何 | 値 |
|---|---|
| 本家の手本 | `libero_spatial/pick_up_the_black_bowl_on_the_ramekin_and_place_it_on_the_plate_demo.hdf5` の 50 デモ |
| うち配布データに入っている組 | **39**（`work/artifacts/libero_states/demo_map.json` に対応表がある） |
| 配布データでのエピソード | **295 本**（1 組あたり 5〜10 本の焼き直し） |
| ラメキンのずれ | 中央 **10.99 mm**・最悪 **245.47 mm**・**1 mm 未満は 0 組** |
| 判定に使った道具 | `solution/tools/contact_clean/score_contact.py`（記録された `states` を読むだけ。再生しない） |
| 動画を作る道具 | `solution/tools/contact_clean/render_contact_videos.py` |

**同じ形の課題がもう 1 つある。**`pick up the black bowl on the cookie box …`
も椀がクッキー箱の上に載っていて、44 組中 38 組が 1 mm を超える。
**ただしずれが 2〜8 mm と小さく、6 組は境目の下に収まった**ので、026 では
「掃除して残った 50 本を 3 倍にする」扱いにした。**この依頼の型が固まったら、
そちらにも当てられる。**

## やること

**手順は決め打ちにしていない。下は種である。**

1. **どこまでなら動かさずに済むかを測る。**椀を真上へ何 mm 上げれば
   ラメキンが 1 mm 未満で済むのか。**そもそも成立するのかを先に確かめる**
   ——載っている物を持ち上げる以上、**接触が切れる瞬間に必ず微小な変位が出る**
   可能性がある。**成立しないなら、そこで打ち切って報告する。**
2. **成立するなら手本を作る。**時間反転や scripted の道具は
   `solution/tools/track3_reversal/` と `solution/tools/scripted_demo/` にある。
3. **作った手本を `score_contact.py` と同じ物差しで測る。**
   1 mm を超えた回は入れない。
4. **動画で確かめる。**`render_contact_videos.py` に食わせられる形にする。
5. **手元の評価をどうするか決める。**`EVAL_TASKS.csv` からこの行を外すのか、
   直した手本で測り直すのか。

## できあがりの条件

| # | 何が揃ったら終わりか |
|---|---|
| 1 | 「1 mm 未満で持ち上げられるか」の答えが、実測値付きで出ている |
| 2 | （成立するなら）手本が `work/artifacts/` に書き出され、全数が 1 mm 未満である |
| 3 | 動画が 3 本以上あり、ラメキンのずれが画面に焼かれている |
| 4 | 手元の評価集合をどう扱うかが決まっている |

## やらなくてよいこと

- **本選 1 の提出には間に合わせなくてよい**（9/17 締切）。**本選 2 か 3 で扱う**
- **`on the cookie box` は触らない。**026 で「掃除して 3 倍」に決めた
- **`libero_90` と配布 tar は使わない**

## 報告の書き方

**表と数値がほしい。**

1. 椀を上げる高さと、ラメキンのずれ（mm）の対応表
2. 成立するかどうかの結論と、その根拠になった実測値
3. 作った手本の本数と、ずれの分布
4. 動画のファイル名
