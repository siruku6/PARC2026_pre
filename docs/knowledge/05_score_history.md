# 05. 本番スコアの全記録（採点ログ 16 本から機械的に抽出）

**出典は `outputs/` の採点ログそのもの。**`docs/howto/02_build_submission.md` の
表は 2 次資料なので使わない。**版・設定・ステップ数・秒数・スコアは、すべて 1 本の
ログの中に揃っている。**

- **版と設定** …… ログ先頭の `[parc] policy_server …` の行
- **ステップ数** …… `POST /act` の出現回数（＝環境を 1 ステップ進めた回数）
- **秒数・スコア** …… 末尾の `合計時間` と `track1: 総合スコア`

```bash
# この表を作り直す
python3 - <<'EOF'
import pathlib, re
for path in sorted(pathlib.Path("outputs").glob("*.md")):
    text = path.read_text(errors="replace")
    server = re.search(r"\[parc\] policy_server ([^\n]+)", text)
    score = re.search(r"総合スコア\s*([0-9.]+)", text)
    if score:
        print(f"{text.count('POST /act'):>5} ステップ  {score.group(1):>6}  "
              f"{(server.group(1)[:60] if server else '')}  {path.name}")
EOF
```

# この表を作り直す（順位表の控えから）
python3 - <<'EOF'
import re, pathlib
lines = [l.strip() for l in
         pathlib.Path("/home/ubuntu/src/tmp/リーダーボード.txt").read_text().splitlines()]
rows, rank, name = [], None, None
for line in lines[1:]:
    if not line or line == "picture":
        continue
    if re.fullmatch(r"\d+", line):
        rank = int(line)
    elif re.fullmatch(r"0\.\d+", line):
        rows.append((rank, name, float(line)))
    else:
        name = line
me = next(r for r in rows if r[1] == "sirukufarios")
print(me, "  1 位:", rows[0][2], "  100 位:", rows[-1][2])
EOF
