
もう一つアイデアが浮かんできました、ものを掴むところまでは IK solver のようなもので制御を行い、掴んだところからの動作は時刻逆向き指令を使う、というのもありかもしれません。

なぜこのアイデアに価値があるかというと、episode 1つ1つでシフトすべき時刻が異なる恐れがあるからです。これは、時間がない私たちにとって大きなリスクではないでしょうか。
そのため、 solver などで自動的に掴むところまでは実現するアイデアが出てきました。

# 新しいアイデアのデメリット

これは単なるアイデアです。切り替わり部分が不自然になり、途中の物体にぶつかったり、最後にものを置く操作で置いたものが揺れたり倒れたりするリスクがあると思っていますので、こちらはこちらで対処すべき問題が残ると思っています。
