## 1. いま何を決めようとしているか

**Track3 で「掴まない」のはなぜか、である。**

対象物の選択は逆向きデータで直った（黄本・缶が正解 1 位・[knowledge/20](../knowledge/20_probe_object_choice_without_rollout.md)）。
**残っているのは掴むところで、動画で見えるのは「正しい物の上で漂って、触らずに 300 歩使い切る」である。**

**原因の候補は 3 つあり、対策が正反対である。**

| 候補 | 対策 |
|---|---|
| 似た物の間で**迷っている** | 弁別データを足す |
| **接近か把持そのもの**が壊れている | 逆向きデータの掴み方を直す |
| **評価時の入力**が学習時と違う | 前処理を直す（データも学習も無関係） |

**だから学習を回す前に切り分ける。**

### 打つコマンド

> **【9/10】1 度目は 18 歩目で落ちた。**`--shm-size` を渡していなかったので
> コンテナの `/dev/shm` が 64 MB になり、DataLoader の worker が
> `unable to allocate shared memory(shm) ... Resource temporarily unavailable` で死んだ。
> **`jaist_launch.sh` に `--shm-size=8g` を足した**ので、**打ち直せばよい**
> （落ちたコンテナは消してある。`work/train/pi05_v2_base24k` は作られていない）。
> **それ以前の 3 本も 64 MB で走っていた**——足りるかどうかが際どく、運で通っていた。


```bash
cd ~/src/PARC2026_pre
RUN=pi05_v2_base24k WEIGHTS=base \
  DATASET=$HOME/data/jaist_mix_v2_x8_base \
  DATASET_REPO_ID=local/jaist_mix_v2_base \
  STEPS=24000 LR=2.5e-5 SAVE_FREQ=8000 CAMERA_AUGMENT=0 FREEZE_CHECK=0 \
  setsid nohup bash solution/train/jaist_launch.sh \
  < /dev/null > ~/launch_pi05_v2_base24k.log 2>&1 &
disown
```

`_hi` は「学習率が高い」の意味で、`pi05_t3rev_v2` の続きに見えてしまう。
**いまは `pi05_clean24k` と同じ土俵の 1 本なので、そちらに揃えた名前にしてある。**

cat ~/launch_pi05_v2_base24k.log                          # 起動時の確認
