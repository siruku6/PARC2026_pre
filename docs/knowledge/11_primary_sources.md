## 再配布物にはライセンスが写っていない

**同じ LIBERO-plus でも配布物が 3 つあり、表記があるのは 1 つだけだった。**

| どこ | ライセンス |
|---|---|
| **`Sylvest/LIBERO-plus`（HF・作者本人）** | **`license: mit` ← 原典** |
| `sylvestf/LIBERO-plus`（GitHub・コード） | LICENSE ファイルが無い |
| `lerobot/libero_plus`（我々が学習に使った再配布版） | カードに `license` 欄が無い |

**使った配布物にライセンスが無くても、「無い」とは限らない。**
**原典まで遡って初めて確定する。**
