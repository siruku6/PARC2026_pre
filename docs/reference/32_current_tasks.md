## 1. いま何を決めようとしているか

**Track3 で「掴まない」のはなぜか、である。**

対象物の選択は逆向きデータで直った（黄本・缶が正解 1 位・[knowledge/20](../knowledge/20_probe_object_choice_without_rollout.md)）。
**残っているのは掴むところで、動画で見えるのは「正しい物の上で漂って、触らずに 300 歩使い切る」である。**

**原因の候補は 3 つあり、対策が正反対である。**

| 候補 | 対策 |
|---|---|
| 似た物の間で**迷っている** | 弁別データを足す |
| **接近か把持そのもの**が壊れている | 逆向きデータの掴み方を直す |
| **評価時の入力**が学習時と違う | 前処理を直す（データも学習も無関係） |

**だから学習を回す前に切り分ける。**
