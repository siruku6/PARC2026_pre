## 1. いま何を決めようとしているか

**Track3 で「掴まない」のはなぜか、である。**

対象物の選択は逆向きデータで直った（黄本・缶が正解 1 位・[knowledge/20](../knowledge/20_probe_object_choice_without_rollout.md)）。
**残っているのは掴むところで、動画で見えるのは「正しい物の上で漂って、触らずに 300 歩使い切る」である。**

**原因の候補は 3 つあり、対策が正反対である。**

| 候補 | 対策 |
|---|---|
| 似た物の間で**迷っている** | 弁別データを足す |
| **接近か把持そのもの**が壊れている | 逆向きデータの掴み方を直す |
| **評価時の入力**が学習時と違う | 前処理を直す（データも学習も無関係） |

**だから学習を回す前に切り分ける。**

### D はどこまで進んだか（2026-09-09）

| 手順 | 状態 |
|---|---|
| v2 を組む | **済**（`work/artifacts/jaist_mix_v2_x8`・6.34 GB・43 課題・992,843 コマ・検査 7 項目通過） |
| **HF へ上げる** | **済**——**`siruku6/jaist_mix_v2`（非公開・新規）**。**既存の `siruku6/jaist_mix`（v1）は触っていない**ので取り違えが起きない。`verify_upload.py` で 41 個・6.34 GB の一致を確認した |
| **JAIST で起こす** | **済**（9/9・**10,000 歩**・3 時間 52 分）。**重みは手元に無く HF `siruku6/pi05_t3rev_v2` だけにある**（`checkpoints/{002000,004000,006000,008000,010000}`・57.75 GB・非公開）。**測るには先に落とす**——`hf download siruku6/pi05_t3rev_v2 --include 'checkpoints/010000/pretrained_model/*' --local-dir work/artifacts/pi05_t3rev_v2` |
| 測り直す | D が終わったら E と A を打ち直す |

```bash
# JAIST 側。落とすのは 1 度だけ
hf download siruku6/jaist_mix_v2 --repo-type dataset --local-dir ~/data/jaist_mix_v2_x8

# D-1 t3rev と 1 変数（5e-6・8,000 歩）。3〜4 時間
RUN=pi05_t3rev_v2 DATASET=~/data/jaist_mix_v2_x8 STEPS=8000 SAVE_FREQ=2000 \
    nohup bash solution/train/jaist_launch.sh > ~/launch_pi05_t3rev_v2.log 2>&1 &

# D-2 pi05_full_local と同じ学習率・歩数（2.5e-5・24,000 歩）。9〜10 時間
RUN=pi05_t3rev_v2_hi DATASET=~/data/jaist_mix_v2_x8 STEPS=24000 SAVE_FREQ=6000 LR=2.5e-5 \
    nohup bash solution/train/jaist_launch.sh > ~/launch_pi05_t3rev_v2_hi.log 2>&1 &
```

**`nohup … &` を付ける理由。**学習そのものは `docker run -d` なので **ssh を切っても走り続ける**が、
**起こしたあとの確認（最初の 20 歩まで最大 30 分待つ）は前面で走る。**
切れるとその出力が失われるので、**ログをファイルへ落として背面に置く。**
**進み具合は `docker logs -f parc-<RUN>`**、確認の結果は `~/launch_<RUN>.log`。

**2 本は同時に走らせない。**JAIST は 20 GB で、1 本で 16.3 GB 使う
（[19](19_weights_catalog.md) の `pi05_t3rev` の行）。**D-1 を見てから D-2 を起こす。**

**D の後は E をそのまま打ち直せばよい。**
`bash solution/tools/probe/run_divergence.sh <新しい重み>` で、
**v2 の記録と比べるなら `PAIRS` に `work/probe_rot2/...` を渡す**
（[plan/22 の 5.3](../plan/22_grasp_and_color_next_moves.md#53-v2-で-1-本学習する手-d本命) にコマンドがある）。
