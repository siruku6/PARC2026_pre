## 1. いま何を決めようとしているか

**Track3 で「掴まない」のはなぜか、である。**

対象物の選択は逆向きデータで直った（黄本・缶が正解 1 位・[knowledge/20](../knowledge/20_probe_object_choice_without_rollout.md)）。
**残っているのは掴むところで、動画で見えるのは「正しい物の上で漂って、触らずに 300 歩使い切る」である。**

**原因の候補は 3 つあり、対策が正反対である。**

| 候補 | 対策 |
|---|---|
| 似た物の間で**迷っている** | 弁別データを足す |
| **接近か把持そのもの**が壊れている | 逆向きデータの掴み方を直す |
| **評価時の入力**が学習時と違う | 前処理を直す（データも学習も無関係） |

**だから学習を回す前に切り分ける。**

## 2. 着手中

**A・B・E が終わった**（2026-09-09）。**残っているのは D と C である。**

| # | やったこと | 出た答え |
|---|---|---|
| **A** | T3 の競合を場外へ移して `proto20` と `rp3000` を 40 本回した | **迷いではない。**手先が対象へ **59 mm より近づいた回が 1 度も無い**。競合を消しても掴めない（[knowledge/21](../knowledge/21_track3_stops_short_of_the_object.md)） |
| **B** | `t3rev` を自分の学習データで 172 コマ、教師強制で測った | **学習は入っている。**43 課題の 94%（順方向）・75%（逆向き）で基準を下回る |
| **E** | **学習データと同じ初期状態から回して、記録された軌跡と並べた**（12 本） | **序盤で経路を外れる。****経路の 1〜4% しか辿れない**（記録どうしは 1〜20 mm、モデルは 37〜120 mm 外れる）。**入力の画は同じ**（1 コマ目の画素差 1/255）。**手首の角度差 15〜87°**（[knowledge/21 の 3.5](../knowledge/21_track3_stops_short_of_the_object.md#35-学習データの経路と並べると14-しか辿れていない9-に足した)） |

**E で読みが 1 つに絞れた。**「対象の近くまで行って止まる」ではなく、
**最初から別の所へ行っている。**そして**回転指令だけは v1 の欠陥と噛み合う**——
**v1 の回転目標はクリップの上限に張り付いていて学べる形ではなく、
モデルは平均へ潰して小さく出している**（p95 0.08〜0.63 対 記録 0.37〜1.00）。

| # | 次にやること | 何が決まるか | 費用 |

| **D** | **v2（回転を封筒内に収めた逆向きデータ）で 1 本学習する** | **回転目標が学べる形になれば手首が掴む姿勢に届くのか。****見る数は `off_mm_median` と `rot_deg_median` である** | 学習 3〜4 時間 |
| C | `PARC_N_ACTION_STEPS=50` で 1 本 | 計画の後半の切り捨てが効いているか | env 変数 1 つ |

**D が本命である。**A・B・E は「データを直せば届く見込み」を残した。
