Track 3の内容について
 公平性の観点から、Track 3の中核となる内容を全参加者に開示します。
 Track 3 は、LIBEROの既存タスクを逆順にしたタスクで構成されます（例: 「AをBに置く」に対して「BからAに戻す」のような、順方向タスクの逆操作にあたるタスク）。

従来の説明との関係
  Track 3 についてはこれまで「既知タスクの組み合わせ／未知ドメイン（言語指示による新規の組み合わせ）」とご説明しており、タスクの構成を参加者に伏せたうえで汎化能力を測る設計としておりました。今回の開示により、当初意図した評価とは異なるものとなりますが、全参加者の条件を揃えることを優先し、このまま実施いたします。当初お伝えした形でコンペティションを提供できなくなったことを、深くお詫び申し上げます。

該当ファイルの扱いについて
 本リポジトリは既に多くの参加者の皆さまがcloneされた状態にあり、既に内容をご覧になった方とそうでない方との間に差が残ることを避けるため、当該ファイルは配布物から削除せず、そのまま残します。なお、個別のタスク内容やタスク数は同ファイルには含まれておらず、これらは引き続き全参加者に対して非公開とします。
