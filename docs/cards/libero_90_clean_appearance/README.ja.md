## 「見た目を振る」とは何か

**4 つの軸を、既定で 25 % ずつ混ぜる。**

| 軸 | 何を変えるか |
|---|---|
| `plain` | 何も変えない |
| `light` | 照明（課題ごとの `_light_N` の bddl） |
| `background` | **机と壁の質感**（課題ごとの `_table_N`・`_tb_N` の bddl） |
| `camera` | 視点 |

**物理は 1 ビットも変わらない**（6 課題 × 4 通りで確かめた）。
**1 本の中では終始 1 つの見た目である**——収録の時点で掛けるので、コマごとには振れない。

**センサ雑音（`_noise_N`）は重ねていない。**外側の後処理でしか掛からず、録画されたコマには乗らない
ためである（学習側に相当するぼかしの水増しが既にある）。

**候補の一覧は台帳にある**（`solution/tools/regen/manifests/l90_appearance_pools.json`。
台所・書斎・居間の 3 系統の `table`・`tb`・`light`）。
**この台帳に視点の軸は無い**——40 課題側の収録とはそこが違う。

## 中身の内訳

**測って確かめた**（腕 6 次元の行動列を sha256 で突き合わせ・2026-09-19）。

| | 本数 |
|---|---|
| 配布 `libero_combined_20hz` に同じ腕の動きがある | 875 / 3,705 |
| **配布データのどこにも無い＝撮り直した手本** | **2,830 / 3,705** |
| `libero_90_clean` と同じ腕の動きがある | 889 / 3,705 |

**見た目を重ねただけなら腕の動きは変わらないはずである。**変わっているということは、
**回し直して録ったものである。**——**だからこのデータは消せない。**

## 分かっている弱点

- **作った手続きが文書になっていない。**本数が 3,911 から 3,705 へ減った理由も、
  実際に使った見た目の配合も、記録が残っていない。**上の内訳は 2026-09-19 に測り直したものである。**
- **混合データセットには使っていない。**公開した模型はどれもこのデータを見ていない。
- `libero_90` には初期姿勢を振った手本が無い（見た目だけである）。
