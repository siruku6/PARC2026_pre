# libero_plus_bowl5_initpose

*English: [README.md](README.md)*

**LIBERO** の操作課題 40 種のための、LeRobot 形式の実演データである。
[`libero_plus_bowl5`](https://huggingface.co/datasets/siruku6/libero_plus_bowl5) と同じ 40 課題を扱い、
**一部を、ロボットの初期姿勢と場面の見た目を振って撮り直した手本に入れ替えてある。**

| | |
|---|---|
| 本数 | **16,820** |
| コマ数 | **2,712,308** |
| 課題数 | **40** |
| 大きさ | 約 22.6 GB |
| 形式 | LeRobot v3.0・20 Hz |

## どう組んだか

`libero_plus_bowl5`（14,085 本。`libero_plus` の、衝突のいちばん多い「丼」5 課題を
撮り直した手本に入れ替えたもの）から始める。

1. **1,532 本を外す**——対象外の物体に触れているもの（基準の 10 コマ目で接触・1 mm 超の変位）か、
   **300 コマを超えるもの**（採点の打ち切りより長い）
2. **3,972 本を撮り直して埋め戻す。**課題ごとの本数は変えない。**すべて初期姿勢を振ってある**
   （モカポット 2 課題を除く。下記）。見た目（照明・机や背景の質感・カメラ）も 25 % ずつ混ぜた
   ——**物理には影響しない**
3. 余りを配って、どの課題も割り当ての本数に届かせる
4. **303 本を足す**（経路 A）——300 コマ超で外した本を、**連続する行動指令をまとめて少ない大きな段にして**
   撮り直し、コマ数に収めたもの。初期姿勢は元のまま振っていない

| | 本数 |
|---|---|
| 土台（`libero_plus_bowl5`） | 14,085 |
| 外した分（接触・300 コマ超。丼の入れ替えで既に直った 965 本を除く） | −1,532 |
| 残した分 | 12,553 |
| 足した分——再生して初期姿勢を振ったもの | +3,453 |
| 足した分——台本で動かしたもの | +511 |
| 足した分——経路 A（縮めた撮り直し） | +303 |
| **合計** | **16,820** |

**撮り直しは、まず元の行動指令をそのまま再生する。**振った初期姿勢のせいで再生が門を通らなくなった
ときだけ、逆運動学（Ruckig）で元の手本の出発姿勢へ寄せる。

**足した本はすべて 3 つの門を通っている。**

1. 300 コマ以内に目標へ届く
2. 対象外の物体を、どの時点でも 1 mm 以上動かさない
3. （再生由来のものは）出発時の手先位置が元の手本から **2 cm 以上**離れている
   ——**意味のある別の出発点になっていること**

## 分かっている弱点

- **モカポット 2 課題には、初期姿勢を振った手本が無い。**振ると 62 回中 1 回しか目標に届かなかった
  （振らなければ 50/50）ので、振らずに置いた。**物体の配置は振ってある**
  （元の人の手本と同じ 50 通りから引いている）。
- **「ramekin の上へ」の丼課題 61 本は、その配置で物理的に届く初期姿勢に偏っている。**
  失敗した 575 回のうち 572 回が、縁を越えて伸ばす途中での腕と ramekin の衝突だった。
- **300 コマ超で外した本が、すべて経路 A で救えたわけではない。**該当 7 課題の 35 組のうち 10 組
  （60 本）と、モカポットの 50 組のうち 25 組は、どの段のまとめ方でも門を通らなかった。
